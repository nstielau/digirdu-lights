# Echo Glow producer enclosure

This is the **Echo Glow** producer variant with a Reverse TFT Feather, 4×8
NeoPixel FeatherWing, and the modeled 19 × 69 mm cylindrical battery. It is a
separate Fusion lineage from the handheld DidgeLights producer revision 11.

- [Current revision 3: domed rail and reset pinhole](revision-3/README.md)
- [Historical revision 2: direct USB](revision-2/README.md)
- [Hardware release and archive workflow](../../RELEASES.md)

The working Fusion document is **Echo Glow producer v1**, cloud version 4.
The new front is plain because the old striped front snapshot has the obsolete
reset opening. Complete F3D and print assets belong in tagged release ZIPs.
