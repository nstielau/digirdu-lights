# Echo Glow producer enclosure

This is the **Echo Glow** producer variant with a Reverse TFT Feather and the
user-measured Ø19 × 69 mm cylindrical battery. The current enclosure has no
pixel wing. It is a separate Fusion lineage from the handheld DidgeLights
producer revision 11.

- [Current revision 4: compact, solid rear cover](revision-4/README.md)
- [Historical revision 3: domed rail and reset pinhole](revision-3/README.md)
- [Historical revision 2: direct USB](revision-2/README.md)
- [Hardware release and archive workflow](../../RELEASES.md)

The working Fusion document is **Echo Glow producer v1**. Cloud version 4 is
the last confirmed version: Fusion accepted the compact revision 4 and its
exterior edge refinement locally while reporting an offline state. Its complete
F3D was exported locally. The front is plain because the old striped front
snapshot has the obsolete reset opening. Complete F3D and print assets belong
in tagged release ZIPs.
