# Hardware

- [Producer enclosures](producer/README.md): Echo Glow producer revision 3 uses
  direct board USB-C, a domed button rail, and reset pinhole. The separate
  DidgeLights microphone producer revision 11 remains a historical reference.

- [Echo Glow consumer enclosure](consumer/README.md): revision 8, Reverse TFT
  Feather, 4×8 NeoPixel FeatherWing, cylindrical battery, direct USB-C, domed
  button rail, pinhole reset, and optional diffuser.

Hardware revisions are independent of firmware versions. Read [the hardware
guidance](AGENTS.md) before editing models and [release workflow](RELEASES.md)
before publishing print kits.
