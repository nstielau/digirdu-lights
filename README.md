# Digirdu Lights

Experiments with microcontrollers, microphones, and LEDs that respond to music.

## Ideas to explore

- Capture sound with a microphone connected to a microcontroller.
- Detect volume, beats, and frequency changes in music.
- Turn audio features into LED colors, brightness, and animation patterns.

Hardware choices, firmware, wiring notes, and experiments will live here as the
project develops.
